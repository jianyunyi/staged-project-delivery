## ISSUE-001：npm 环境配置告警
证据：evidence/s1-tests.log。运行 npm test 即输出 Unknown env config http-proxy，随后 5 个测试通过。根因已验证为 npm 识别环境配置警告，非应用失败。影响是未来 npm 兼容性；当前不影响验收。排查：package.json 唯一脚本 npm test，无安装/构建/lint/typecheck 脚本；当前应用无需依赖。方案：保留环境不修改；替代为直接 node --test 可运行但不能掩盖 npm 的原始证据。决策来源：既有仅本目录授权，无需改变外部环境。验证：S2 同时运行 npm test 和 node --test；回退：不适用，无修复改动。修复轮次：0。

S2 复验：evidence/s2-tests.log 仍有同一环境告警，9项通过；evidence/s2-node-tests.log 直接运行 node --test，9项通过且无该告警。没有应用失败或修复轮次，ISSUE-001 保留延期状态。
